# Notebook Guide

This folder contains the original notebook-based lab material used during the project.

## Purpose

- demonstrate the main ideas explored during each lab session
- keep the experimentation workflow visible alongside the cleaned Python modules
- provide quick visual checks for QAOA, Grover, annealing, and classical optimization experiments

## Suggested Reading Order

- `quant_algo_lab1.ipynb`: original worksheet-style introduction to problem formulations
- `bell_state.ipynb`: simple two-qubit entanglement example
- `grover.ipynb`: Grover search, transpilation, and noise effects
- `qaoa_test_max_cut.ipynb`: QAOA parameter landscape on a small MaxCut-inspired Ising model
- `qaoa_optimizer_test.ipynb`: QAOA depth and noise study
- `qa_noiseless_simulation.ipynb`: noiseless adiabatic spectrum analysis
- `qa_noisy_simulation.ipynb`: noisy adiabatic spectrum analysis
- `benchmark_sa.ipynb` and `sa_parameters_analysis.ipynb`: simulated annealing benchmarking and parameter studies

## Note

The notebooks are kept for readability and course continuity. The maintainable, reusable implementation is provided by the Python packages in the repository root.
