# Quantum Algorithms Lab Sessions (ESILV)

This repository contains the coursework and Jupyter Notebooks for the ESILV Quantum Algorithms lab sessions. The focus of these labs is to bridge the gap between quantum computing theory and practical implementation using IBM's **Qiskit** framework.

Throughout the sessions, we explore everything from foundational quantum mechanics concepts to advanced, hardware-constrained algorithm simulations.

## 🧰 Prerequisites

To run the notebooks in this repository, you will need Python installed along with the following libraries:
* `qiskit`
* `qiskit-aer`
* `numpy`
* `matplotlib`

You can install the dependencies using:
`pip install qiskit qiskit-aer numpy matplotlib`

## 🧪 Lab Sessions Overview

* **Lab 1: Introduction to Qiskit**
  An introduction to the Qiskit framework. This session covers the creation of basic quantum circuits, applying fundamental single and multi-qubit gates, and visualizing quantum states and measurements.

* **Lab 2: Foundational Quantum Protocols**
  Exploration of core quantum mechanics principles applied to algorithms, focusing on superposition, entanglement, and simple circuit execution.

* **Lab 3: Introductory Quantum Algorithms**
  Implementation of early quantum algorithms designed to demonstrate quantum advantage over classical counterparts by evaluating specific functions in fewer steps.

* **Lab 4: Advanced Algorithms & State Manipulation**
  Diving deeper into complex quantum transformations and phase manipulation, preparing the groundwork for advanced search and factorization algorithms.

* **Lab 5: Grover's Algorithm & Hardware Constraints**
  A comprehensive implementation of Grover's search algorithm. This lab includes building the oracle and diffusion operators, observing amplitude amplification, and analyzing the destructive impact of transpilation and simulated hardware noise on deep circuits.

## 🚀 How to Run

1. Clone the repository to your local machine.
2. Ensure you have the required dependencies installed.
3. Launch Jupyter Notebook (`jupyter notebook` or via VS Code).
4. Open the respective `.ipynb` files and run the cells sequentially.
